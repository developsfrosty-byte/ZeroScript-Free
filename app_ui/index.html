Setup & Pro Workflow

Everything runs silently in the background via this desktop app.

01

Load / Reload the Extension

Open edge://extensions or chrome://extensions, enable Developer mode, load zeroscript-extension, and click Reload (↻) after updating.

02

Connect Roblox Studio MCP

Open a place in Roblox Studio, open Assistant Settings > MCP Servers, toggle Enable Studio as MCP server on, and run our Health Doctor anytime.

Apply a 1-click skill pack in Skills (UI, Combat VFX, NPC AI, Architecture, Lighting, Networking) and set always-on project rules in Prompts.

04
