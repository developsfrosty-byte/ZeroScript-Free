Setup & Pro Workflow Guide

Everything runs silently in the background via this desktop app — no terminal window needed.

01

Load the Chrome Extension

Open chrome://extensions, turn on Developer mode, click Load unpacked, and pick the zeroscript-extension folder.

02

Enable Roblox Studio MCP

Open a place in Roblox Studio, open Assistant Settings > MCP Servers, and toggle Enable Studio as MCP server on.

03

Equip Overpowered Skills

Built-in UI, Building, and Cutscenes playbooks automatically teach any AI agent AAA Studio craft — customize or add your own in Environment.

04

Pick an AI & Start Building

Open DeepSeek, ChatGPT, Gemini, or any supported provider, then click ▶ Start Roblox agent in the composer bar.
